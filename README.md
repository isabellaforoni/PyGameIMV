#Sobre o jogo

Inspirado no jogo do dinossauro do Google, o objetivo é chegar até o Papai Noel, que está bem longe.
O personagem fica parado e o chão vem na direção dele, trazendo obstáculos:

| Obstáculo        | Tipo | Como passar |
| Arbusto          | baixo| pular       |
| Árvore           | baixo| pular       |
| Árvore com luzes | baixo| pular       |
| Bengala de doce  | alto | abaixar     |

- O personagem tem apenas uma vida só: encostou em um obstáculo, perdeu (YOU DIED!).
- Pelo caminho aparecem presentes, que são somados no contador no topo da tela.
- A barra "Até o Papai Noel" mostra quanto falta. No fim da corrida o Papai Noel aparece; encoste nele para vencer (YOU WIN! Congrats!).
- O jogo vai ficando mais rápido com o tempo, e o recorde de presentes fica salvo no arquivo `recorde.txt`.
- Personagens: Rena, Gnomo ou Gingerbread.

#Controles

| Ação                              | Mouse (botões na tela)                 | Teclado         |

| Pular                             | seta ↑ (canto inferior direito)        | ↑, espaço ou W  |
| Abaixar (segure)                  | seta ↓ (canto inferior direito)        | ↓ ou S          |
| Pausar                            | botão de menu (canto superior direito) | ESC ou P        |
| Começar / jogar de novo           | START / seta circular                  | Enter ou espaço |
| Trocar de personagem (tela final) | —                                      | ESC             |
| Música liga/desliga               | botão da nota musical                  | —               |

Dica: apertar "abaixar" no meio do pulo faz o personagem cair mais rápido.
